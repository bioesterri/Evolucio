# PR-45 — Comparació de runs, controls i múltiples llavors

## Resum

- Defineix experiments versionats amb un baseline, controls, variants i un conjunt comú de llavors.
- Congela el pla abans d'executar-lo mitjançant el batch existent.
- Classifica diferències de configuració, audita la cobertura i valida una sola trajectòria per cas i llavor.
- Calcula distribucions i contrasts aparellats amb Polars a partir de les mètriques PR-43/44.
- Exporta taules, informe llegible i procedència dels artefactes. Admet anàlisi temporal i bootstrap exploratori.

## Verificació funcional

L'exemple versionat compara mutació activa amb tres controls, en tres
llavors comunes i sis passos. El control sense mutació combina les dues
taxes a zero i la prova d'integració verifica l'herència amb els genomes
retinguts. El control ambiental conserva la condició inicial. El control
de recursos modifica l'estoc inicial i la capacitat per cel·la.

Cobertura revisada amb llavors absents, selecció explícita d'una recuperació,
telemetria incompleta, extinció censurada i neutralitat de la mida del chunk.

## Abast científic

Les diferències descriuen efectes observats dins el disseny i l'horitzó.
Es conserven les absències i exclusions amb el seu motiu. El control amb
agents aleatoris fixos requereix una política de motor definida en un PR propi.
